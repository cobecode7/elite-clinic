🏥 عيادة النخبة الطبية (Elite Clinic)

نظام ويب متكامل (Full-Stack) لإدارة العيادات الطبية متعددة التخصصات. يوفر للمريض تجربة حجز إلكتروني سلسة ومريحة، ويزود الإدارة بلوحة تحكم احترافية وآمنة لمراقبة الحجوزات وإدارة الأطباء والمواعيد.

تم بناء الواجهة الأمامية بأسلوب Neo-Brutalism العصري (ألوان زاهية، حدود سميكة، وظلال صلبة)، مع خلفية برمجية قوية وآمنة باستخدام Node.js و Express و Sequelize ORM.
✨ الميزات الرئيسية
👤 واجهة المريض (Frontend)

    تصميم متجاوب بالكامل: يعمل بكفاءة عالية على جميع الأجهزة (جوال، تابلت، حاسوب).
    عرض ديناميكي للأطباء: يتم جلب قائمة الأطباء تلقائياً من قاعدة البيانات وعرضها في الصفحة الرئيسية.
    نافذة حجز منبثقة (Pop-up Modal): لتسهيل عملية الحجز دون مغادرة الصفحة، مع رسائل تأكيد تفاعلية (Toast Notifications).
    حجز ذكي: يختار المريض القسم الطبي، الطبيب، يوم الحجز، والوقت المحدد.
    تحقق فوري من المدخلات: التأكد من صحة البيانات (مثل صيغة رقم الجوال) قبل إرسالها للسيرفر.

🛠️ لوحة تحكم الإدارة (Admin Dashboard)

    نظام مصادقة آمن (Authentication): تسجيل دخول للأدارة باستخدام الجلسات (Sessions) مع تشفير كلمات المرور (bcryptjs).
    لوحة إحصائيات سريعة: عرض إجمالي الحجوزات، الحجوزات المعلقة، وعدد الأطباء المسجلين.
    إدارة الحجوزات (CRUD): تأكيد الحجز، حذفه، أو فلترته (عرض الكل / المعلقة / المؤكدة).
    إدارة الأطباء: إضافة طبيب جديد ليظهر فوراً في واجهة الموقع الرئيسية.
    تتبع موعد الحجز: تعرض لوحة التحكم اليوم والوقت المحدد الذي اختاره المريض لحجزه.

🛡️ الأمان والأداء (Security & Performance)

    Helmet: لتأمين HTTP Headers وتفعيل سياسات أمان المحتوى الصارمة (CSP) لمنع هجمات XSS.
    Rate Limiting: لمنع هجمات السبام (Spam) وتحديد عدد محاولات تسجيل الدخول والحجوزات الفاشلة.
    Zod: للتحقق الصارم من البيانات (Schema Validation) القادمة من الواجهة قبل إدخالها لقاعدة البيانات.
    Event Delegation: استخدام أحدث تقنيات الجافاسكربت للتعامل مع عناصر الـ DOM الديناميكية بشكل آمن.

🛠️ التقنيات المستخدمة (Tech Stack)
الجزء	التقنية
الواجهة الأمامية (Frontend)	HTML5, CSS3, Vanilla JavaScript (ES6+)
الخادم (Backend)	Node.js, Express.js
قاعدة البيانات (Database)	Sequelize (ORM), SQLite (للتطوير), PostgreSQL (للإنتاج)
الأمان والتحقق (Security)	Helmet, express-rate-limit, bcryptjs, Zod
إدارة الجلسات (Sessions)	express-session

🚀 طريقة التشغيل محلياً (Local Setup)

اتبع هذه الخطوات لتشغيل المشروع على جهازك:
استنساخ المستودع:git clone https://github.com/your-username/elite-clinic.git
cd elite-clinic
npm install
تعبئة قاعدة البيانات ببيانات تجريبية (Seeder):
(هذا الأمر سينشئ قاعدة البيانات، ويضيف 5 أطباء، 5 حجوزات، وحساب أدمن)
npm run seed
npm run dev
    افتح المتصفح واذهب إلى:
         الموقع الرئيسي: http://localhost:3000
         لوحة التحكم: http://localhost:3000/admin

🔄 الانتقال إلى PostgreSQL للنشر (Production)

المشروع مهيأ للانتقال من SQLite إلى PostgreSQL بخطوة واحدة دون تغيير أي كود برمجي:

    قم بإنشاء ملف .env في المجلد الرئيسي وأضف المتغيرات التالية:
    env
     
      

 
 
NODE_ENV=production
DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost


    قم بتشغيل npm start وسيقوم السيرفر تلقائياً بالاتصال بـ PostgreSQL وإنشاء الجداول.
